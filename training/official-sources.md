# Official and Authoritative Sources for OpenClaw Updates

These are the **only official documentation, repositories, and first-party project sources** agents should use. No third-party blogs or aggregators.

---

## 1. OpenClaw Official GitHub Repository

https://github.com/openclaw/openclaw

This is the **most important source**.

Monitor:
- commits
- release tags
- pull requests
- issues
- discussions

This repository contains the **actual codebase for the OpenClaw gateway and agent runtime**.

Key sections to watch:

**Releases**
https://github.com/openclaw/openclaw/releases
This is where new versions are published.

**Issues**
https://github.com/openclaw/openclaw/issues

**Discussions**
https://github.com/openclaw/openclaw/discussions

## Recommended Monitoring Strategy for an AI Agent

Check in this priority order:

1. GitHub repo (commits, issues, discussions)
2. GitHub releases
3. docs.openclaw.ai
4. GitHub discussions
5. openclaw.ai blog

Ignore:
- random GitHub forks
- unverified tutorials
- third-party blog guides
- YouTube install guides
- SEO content sites
- AI-generated install pages

Only rely on:
- official GitHub repositories
- official documentation
- official announcements
